## Download / 下载

Download **Shiyu-Windows-x64.zip** below, extract the entire ZIP, then open **Shiyu.exe**.
No Python or Git installation is required. Keep the `_internal` folder beside the EXE.
The automatically generated “Source code” downloads are for developers.

## Included

- Select one contact or group and export the conversation to Word (.docx).
- Message dates, times, sender names, text, and locally decoded images.
- Image replies matched to original messages in the same conversation.
- Offline archives for later export without another WeChat login.

Windows 10/11 x64; Chinese interface. Live import tested with WeChat 4.1.13.12.
Other WeChat versions and unavailable images may not work. This is an unsigned portable build.

First run: select your own WeChat data directory, start detection, fully exit and restart
WeChat, then log in. Follow the app prompts to open a chat image and read the records.

Built from source on GitHub, tested, and checked again after ZIP extraction.
Includes runtime dependencies and notices; no personal chats or account configuration.
SHA256SUMS.txt contains the download checksum.
